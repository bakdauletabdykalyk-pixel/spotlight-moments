# Spotlight Moments

Create a premium, cinematic, modern website for a hospitality technology concept called SPOTLIGHT DINING.

The website should feel like a combination of:

luxury fine dining

cinematic lighting

premium hospitality

futuristic technology

Apple-level simplicity

high-end Dubai restaurant aesthetics

This is NOT a typical restaurant website.

Spotlight Dining is a technological experience layer that can be added to an existing restaurant. It uses spotlights, lighting scenes and subtle projections to turn an ordinary dinner into a memorable event.

The restaurant does NOT need to change its:

kitchen

menu

staff

internal operations

Spotlight Dining simply adds a new layer of guest experience.

DESIGN SYSTEM

Overall aesthetic:

Luxury + cinematic + technology.

Background:

Almost black / charcoal.

Primary typography:

Modern premium sans-serif.

Use large editorial typography.

Typography should feel similar to:

Apple

Aesop

high-end hospitality brands

luxury architecture websites

Avoid:

generic startup gradients

excessive glassmorphism

excessive rounded cards

neon cyberpunk

cheap animations

excessive shadows

generic SaaS dashboard styling

Accent colors:

Warm gold / champagne light.

Secondary accent:

Very subtle deep blue.

The blue should be sophisticated, not neon.

ANIMATION

Use smooth premium animations.

Recommended:

fade-in

slow scale

parallax

spotlight movement

image transitions

text reveal

smooth hover states

scroll-triggered animations

Animations should be slow and elegant.

The website should feel cinematic rather than flashy.

Use Framer Motion or another modern animation library if appropriate.

RESPONSIVE DESIGN

The website must be fully responsive.

Desktop:

cinematic full-screen sections

large typography

immersive imagery

Mobile:

preserve the premium aesthetic

vertical cards

simplified animations

easy booking

CTA always accessible

Do not simply shrink the desktop design.

Design the mobile experience intentionally.

IMPORTANT BRAND POSITIONING

Spotlight Dining should NOT look like:

a lighting company

a nightclub

a projector company

a restaurant booking platform

Instead, it should look like:

a premium hospitality technology company that creates memorable dining experiences.

The website should make someone immediately understand:

“This technology can be added to an existing restaurant and create an entirely new guest experience without changing the restaurant’s core operations.”

FINAL FEEL

Imagine:

A luxury restaurant in Dubai at 10 PM.

The room is dark.

One table is illuminated.

A dish arrives.

The light follows it.

Everyone at the table looks toward it.

For a few seconds, the entire room disappears.

That feeling is the product.

The website must sell THAT feeling.

Make the website feel premium, mysterious, cinematic, sophisticated and technologically advanced.

Do not make it feel like a generic template.
